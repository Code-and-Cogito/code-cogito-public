# Article 03 — Great Depression vs 2008 Financial Crisis

**1929 vs 2008: two crashes, two recoveries — what did we learn (and what did we forget)?**

Using Python to compare leverage evolution, simulate agent-based bank runs, model credit spirals, track unemployment cascades, measure wealth inequality, and compare recovery timelines.
