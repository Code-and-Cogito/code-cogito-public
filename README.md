## About

This repository contains the free, open-source Python code accompanying [Code & Cogito](https://code-cogito.com) blog articles. Each script is a standalone, runnable analysis that demonstrates the core concepts discussed in the corresponding article.

## Start here

New to the repo? The free **[Starter Notebook](https://codecogito.gumroad.com/l/starter-notebook?utm_source=github&utm_medium=readme&utm_campaign=starter&utm_content=main_readme)** is the quickest way in: one real public dataset (Maddison Project GDP per capita, 1500–2022, CC BY 4.0), one small model, three figures, and about 30 minutes from download to finished analysis. English, Traditional Chinese and Japanese editions are included; enter 0 at checkout.

## Quick Start

```bash
# Clone the repository
git clone https://github.com/Code-and-Cogito/code-cogito-public.git
cd code-cogito-public

# Install dependencies
pip install -r requirements.txt

# Run any script
python series-01-renaissance/article-01-florence/florence_network_analysis.py
```

## Data & limitations

Each article's analysis is labelled below by the kind of data it uses. No script in this repository loads a public dataset: every number is written into the code, often as a simplified or illustrative series. Treat the figures as teaching material for the method, and check primary sources before reusing them. (The free Starter Notebook is the exception: it reads the Maddison Project Database, CC BY 4.0.)

- **Reconstructed series** — historical or market figures typed in by hand; approximate.
- **Random simulation** — output of a random-number model.
- **Illustrative values** — numbers chosen to explain an idea; not measurements.
- **Mixed** — two or more of the above.
