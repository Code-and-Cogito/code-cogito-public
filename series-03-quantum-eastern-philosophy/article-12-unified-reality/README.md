# Article 12 — Unified View of Reality

**11 structural correspondences between quantum mechanics and Eastern philosophy. Coincidence, or convergence?**

Using Python to draw the network of the 11 correspondences, chart five recurring themes, and compare two paths to understanding reality. The scores and the shared themes are the author's own interpretation, not measured results or established physics.

## Quick Start

```bash
pip install numpy matplotlib networkx
python unified_reality_analysis.py
```

The script saves three PNG files in the current folder. To run it without opening plot windows, set `MPLBACKEND=Agg` first.

## Charts

- `correspondences_network_basic.png` — Network of the 11 quantum-Eastern correspondences (line thickness = hand-set illustrative score)
- `five_patterns_basic.png` — Five recurring themes with hand-set illustrative scores
- `two_paths_basic.png` — Two paths (Western science and Eastern philosophy), compared

The scores in these charts are the author's own hand-set illustrations, not measurements and not computed from data. The article's text distils three patterns (relationality, the participatory role of the observer, transcending binary opposition); the chart lists two more themes, Fundamental Uncertainty and Wholeness.
